# Save method for SpacetimeviewList

Converts a SpacetimeviewList to a spacetimetabs widget and displays it

## Usage

``` r
save.SpacetimeviewList(x, file, ...)
```

## Arguments

- x:

  A SpacetimeviewList object

- file:

  The file path to save the HTML file to

- ...:

  Additional arguments passed to print

## Value

The SpacetimeviewList object (invisibly)
